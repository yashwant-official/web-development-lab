
# P11 - Newspaper Layout using CSS Grid

## Objective
To create a newspaper-style webpage using CSS Grid layout.

## Concepts Used
- CSS Grid
- grid-template-columns
- grid-template-areas
- grid-area
- Grid gap
- Nested CSS Grid
- Flexbox navigation
- Responsive media queries

## Files
- index.html
- style.css
- README.md

## Result
Created a responsive newspaper webpage containing a header, navigation bar, featured news, news cards, sidebar, and footer.

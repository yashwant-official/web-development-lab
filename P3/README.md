
# P3 - Feature Branch Git Workflow

## Objective
To understand and implement the feature branch workflow using Git.

## Steps Performed
1. Created a feature branch.
2. Added portfolio HTML content.
3. Committed changes to the feature branch.
4. Pushed the feature branch to GitHub.
5. Merged the feature branch into main.

## Technologies Used
- HTML
- Git
- GitHub

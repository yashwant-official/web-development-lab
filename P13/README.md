
# Practical 13: Choosing Between Flexbox and CSS Grid

## Objective
To understand the differences between CSS Flexbox and CSS Grid and learn when to use each layout system.

## Concepts Covered
- One-dimensional layouts using Flexbox
- Two-dimensional layouts using CSS Grid
- `display: flex`
- `display: grid`
- `justify-content` and `align-items`
- `grid-template-columns`
- Responsive layouts using media queries

## Conclusion
Flexbox is useful for arranging elements in a row or column. CSS Grid is useful for creating layouts with rows and columns. Both can be combined to build responsive websites.
